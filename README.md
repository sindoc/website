# SinDoc Public Graph

This repository is the public-facing knowledge graph and concept-publishing surface for the wider workspace.

The content is maintained in a Logseq-friendly structure and mirrored into publishable pages.

Current emphasis:

- data and AI governance
- reference data management
- public concept notes that relate back to Singine and adjacent work

Use the canonical path `~/ws/git/github/sindoc/website` when editing or publishing from the command line.
